# CuteClothesly – E-Commerce Web Application

## 🌐 Live Demo
https://cuteclothessly-web.vercel.app

CuteClothesly is a web-based e-commerce application built using Next.js. This project is designed to display and manage fashion products with a clean and responsive user interface.

## 📌 Overview
This application allows users to browse clothing products easily. It focuses on simplicity, user experience, and modern web design.

## 🚀 Features
- Product catalog display
- Responsive design
- Product image integration
- Simple and user-friendly interface

## 🛠️ Tech Stack
- Next.js
- React.js
- JavaScript

## ⚙️ Getting Started

Install dependencies:
```bash
npm install

Run the project:

npm run dev

Open in browser:
http://localhost:3000
